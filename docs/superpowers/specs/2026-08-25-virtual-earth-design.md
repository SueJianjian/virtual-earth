# 虚拟地球首版设计

日期：2026-08-25

## 1. 目标与边界

创建一个 2D 自然地图沙盒：世界从原始、无生命状态开始，在约 15 分钟的默认模拟时间内自行演化到早期稳定生态。用户拥有上帝模式，可以直接改变地形、气候、水文、资源、生命和灾害，但所有干预都必须进入同一套世界事件系统，并通过后续规则产生连锁影响。

首版分为两个连续阶段：先让生产者、消费者和分解者形成可持续的生态网络，再允许智慧生命、文化、神话和修真路径在满足条件后自行涌现。首版不追求完整现代文明，而是验证从自然生态到早期文化与超自然体系的连续演化。

非目标：高保真地球物理、真实板块动力学、真实物种个体行为、完整现代文明、联网多人、LLM 驱动叙事和 3D 地球视图。

## 2. 用户体验

用户进入后看到刚冷却的原始星球，模拟自动运行。主界面包含：

- 左侧大面积 2D 地图，支持缩放、拖拽和横向环绕；
- 右侧状态面板，显示地球年、演化阶段、平均温度、海洋覆盖率、总生物量和物种数量；
- 底部时间控制，提供暂停、`1x / 4x / 16x / 64x` 加速、重置、保存和加载；
- 图层选择，包含自然、温度、降水、营养、生物量和物种分布；
- 事件时间线，记录海洋形成、有机分子出现、光合生物扩张、多细胞生命出现和复杂生态建立等事件。

地图工具栏提供上帝模式：

- 地形：升高、降低、塑造山脉和海岸；
- 水文：添加海水、淡水、河流和湖泊；
- 气候：加热、降温、增加和减少降雨；
- 地质：火山、地震和陨石；
- 资源：增加矿物、营养盐和有机物；
- 生命：投放或删除指定种群；
- 灾害：干旱、洪水、寒潮和火山冬天。

点击地图单元格后显示该区域的海拔、温度、湿度、水量、营养、生物量和种群构成。每次干预都带时间戳进入事件日志。

## 3. 总体架构

首版采用 `TypeScript + Canvas 2D + Web Worker`。模拟核心是纯 TypeScript 模块，不直接依赖 DOM 或渲染 API。主线程负责界面和地图绘制，Worker 负责时间步计算，通过结构化消息传递世界快照、事件和控制命令。

世界使用横向环绕的二维网格。每个格子拥有固定尺寸和稳定索引，避免地图缩放或动态内容改变布局。模拟使用双缓冲：每个时间步只从上一时刻的完整状态读取，并写入下一状态，完成后交换缓冲。

建议的模块边界：

- `world`：种子、网格、时间、随机数状态和版本化快照；
- `geology`：海拔、岩石、火山和缓慢的地质漂移；
- `climate`：纬度、太阳辐射、温度、风向和降水；
- `hydrology`：海洋、河流、蒸发、降雨、径流和淡水储量；
- `chemistry`：碳、氮、磷、矿物质、有机物和氧气；
- `ecology`：种群增长、迁移、竞争、捕食、变异和灭绝；
- `culture`：智慧种群、语言、记忆、信仰、组织和知识传播；
- `worldview`：神话、修真及其他体系包的条件检查、规则交互和事件生成；
- `events`：上帝模式命令、自然事件、时间线和事件回放；
- `rendering`：自然地图、分析图层、选区和图例；
- `persistence`：JSON 存档和版本迁移。

## 4. 模拟规则

### 地质与原始环境

初始地形由确定性噪声和纬度约束生成，包含少量高地、盆地和海洋。首版用缓慢地质漂移与火山事件制造地形变化，不实现真实板块物理。初始世界没有种群，化学物质以少量无机资源开始。

### 气候与水文

温度由纬度、海拔、海洋邻近度、云量和大气状态共同决定。降水由蒸发、湿度、风向和地形抬升产生。水文更新包含蒸发、降雨、地表径流、淡水汇聚和海洋交换。所有水量更新必须通过守恒检查，允许显式的蒸发到大气和降水回地表转移。

### 化学与生命起源

化学层追踪碳、氮、磷、矿物质、有机物和氧气。原始环境在温度、水量、矿物质和能量满足条件时，以概率方式产生化学自组织事件，再生成最初的生产者种群。该过程是游戏化压缩的科学近似，不宣称复现真实生命起源。

### 种群生态

生态层以种群而非单个生物为全球模拟单位。每个种群拥有：能量需求、最适温度、最适湿度、移动能力、食物类型、繁殖速度、寿命和变异幅度。种群适应度由环境适宜度、资源、捕食、疾病和邻近种群竞争共同决定。

生产者利用光照、水和营养增长；消费者消耗指定食物并向更高营养级传递能量；分解者处理死亡有机物并将营养返还环境。种群可迁移、繁殖、产生变异和灭绝。变异产生新物种记录，灭绝保留在事件日志中。

### 时间压缩

- 原始地质和海洋阶段：数百万年压缩到几十秒；
- 化学演化阶段：数十万年压缩到几十秒；
- 生态扩张阶段：数千至数万年压缩到数分钟；
- 默认一局约 15 分钟；暂停和 `1x / 4x / 16x / 64x` 速度对模拟时钟生效。

固定种子必须产生可复现结果；不同种子允许出现不同的物种谱系、地形和事件序列。

## 5. 数据与事件

世界快照至少包含：

- 世界种子、模拟时间、阶段和随机数状态；
- 地形、气候、水文、化学网格；
- 种群列表及遗传参数；
- 智慧种群、文化、信仰、组织和知识状态；
- 已启用的体系包、已发现规则和超自然实体状态；
- 事件日志和模拟版本。

事件分为自然事件和用户事件。用户事件包括位置、类型、强度、持续时间、创建时间和来源。模拟器在每个时间步消费事件并生成自然反馈，例如加热操作先改变温度场，再影响蒸发、降水、生产者和消费者。

存档格式为带版本号的 JSON。加载时执行版本检查；首版只需要支持当前版本，但数据结构必须允许未来迁移。

## 6. 错误处理与稳定性

- Worker 计算异常时暂停模拟并将错误显示在状态面板，不静默丢失世界状态；
- 存档解析失败时保留当前世界，并提示用户选择重试或重置；
- 对温度、水量、营养和生物量设置显式上下界，防止数值爆炸；
- 每个时间步对水量、能量和关键化学物质执行守恒或边界检查；
- 事件队列按时间排序，重复加载或重复发送控制命令不能重复施加同一事件。

## 7. 验证标准

### 单元测试

- 固定种子生成相同初始地形；
- 温度随纬度和海拔变化方向正确；
- 水循环不会无故增加或消失水量；
- 生产者、消费者和分解者增长与资源约束一致；
- 种群可以迁移、变异和灭绝；
- 事件强度与持续时间生效一次且可记录。

### 模拟测试

- 原始世界能进入海洋和相对稳定气候阶段；
- 固定种子在相同步数下的关键指标一致；
- 暂停后继续不会跳变或重复计算；
- 至少一个测试种子能形成生产者、消费者和分解者；
- 灾害和环境干预能改变后续指标与事件日志。
- 没有预置神祇、宗门或功法时，系统不会在开局直接生成它们；
- 体系只有在条件满足时才会出现，并且同一体系可以自然失败、融合或消亡；
- 固定种子能够复现文化、神话和修真事件的顺序与关键状态。

### 浏览器检查

- 初始地图非空且图例与图层颜色匹配；
- 模拟时间持续增加，速度切换生效；
- 选区数据与地图位置一致；
- 上帝模式工具有可见反馈，操作后事件出现在时间线；
- 保存并加载后世界指标和地图状态恢复；
- 桌面和窄屏布局中控件和文字不重叠。

## 9. 后续扩展

文明层将以生态层输出为输入，增加智慧种群、记忆、语言、协作、资源占有和聚落。它应复用区域网格、种群接口、事件日志、干预工具和存档格式，不改变首版生态模拟的基本契约。3D 地球视图也只消费世界快照，不把 3D 渲染逻辑引入模拟核心。

## 10. 自主世界观与超自然体系

### 自主涌现原则

神话、神祇、修真、宗门和其他超自然体系都不能由脚本强行推进。它们作为潜在规则、资源转化关系和触发条件存在，开局不预置神祇、宗门、教团、功法或修士。只有当生态、智慧生命、文化传播和环境资源满足条件时，相关实体和组织才可能自然出现。

上帝模式默认关闭。用户可以主动开启实验干预，但干预只能提交世界事件，不能直接宣布某个文明已经拥有神祇、某个生物已经飞升或某个体系已经胜利。系统必须允许自然产生的体系失败、融合、变异和消亡。

### 体系包接口

每个世界观体系以 `WorldviewPack` 描述，分为三部分：

- 设定数据：实体、资源、组织、称谓、母题、关系和视觉标记；
- 规则扩展：出现条件、资源转化、传播、冲突、融合、衰退和消亡规则；
- 事件模板：祭祀、神迹、启示、战争、发现、修炼、突破、渡劫和灾变事件。

体系包不能直接修改其他模块的内部数组，只能通过统一接口读取区域状态、文化状态、资源状态和已发生事件，并提交带来源和时间的世界事件。这样可以让不同体系相互作用，同时保持模拟可复现。

### 首版示范体系

首版接入五个示范包：

- 中国神话：自然神灵、祖先崇拜、天命、妖灵和神人关系等母题；
- 希腊神话：多神谱系、英雄崇拜、神谕、命运和城邦祭祀等母题；
- 北欧神话：诸神族群、符文、预言、英雄传统和末日循环等母题；
- 印度神话：神祇与阿修罗、业力、轮回、宇宙周期和苦行等母题；
- 修真体系：灵气、资质、功法、境界、寿命、宗门、法宝、渡劫和因果。

这些包以原典母题为基础，但不复制具体现代作品内容，允许在虚拟世界中发生架空融合。修真体系是可叠加到不同文明上的发展路径，不绑定单一民族或单一神话包。

### 自主演化链

系统按以下可能但非必然的链条推进：

`生态稳定 -> 智慧生命 -> 语言与记忆 -> 祖先或自然崇拜 -> 祭祀与组织 -> 神话分化 -> 神迹或超自然实体 -> 体系竞争/融合`

修真路径可以从灵气环境、长寿个体、知识积累和社会传承中独立发现，也可以与神话体系融合。不同文明可能独立产生相似母题，也可能因迁徙、贸易、战争和通婚而互相改写。每个事件都由条件、概率、传播范围和资源约束共同决定，而不是按固定剧情播放。

### 其他体系

首版不预装更多具体体系，但保留同样的 `WorldviewPack` 接口。后续可接入魔法、科技神权、外星文明、灵魂轮回、异能、机械神、梦境世界等体系。新增体系必须提供出现条件、资源闭环、传播机制、冲突规则、失败条件和测试种子，不能只添加静态名称或事件文本。
